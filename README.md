# Examen_sitioP

Sitio web personal de Danna Segura, desarrollado con HTML, CSS y Bootstrap.

## Ver el sitio localmente

Abre `index.html` en un navegador. La página de contacto está en `contacto.html`.

## Publicar con GitHub Pages

El flujo de trabajo de GitHub Actions publica automáticamente el contenido de este repositorio cuando se suben cambios a `main`. Después de crear el repositorio, entra a **Settings → Pages** y selecciona **GitHub Actions** como fuente de publicación.

El sitio estará disponible en `https://<usuario>.github.io/Examen_sitioP/` una vez que termine la primera publicación.
